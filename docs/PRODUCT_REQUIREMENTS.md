# Requisitos funcionales iniciales

- RF-001: seleccionar objetivo de 50, 100 o 200 puntos antes de crear una mesa.
- RF-002: registro e inicio de sesión por correo.
- RF-003: inicio con Apple ID.
- RF-004: inicio con Facebook.
- RF-005: perfil unificado por usuario.
- RF-006: modalidades clásico, mano a mano y abierto.
- RF-007: menú con perfil, amigos, búsqueda, configuración, ayuda, soporte, privacidad y cierre de sesión.
- RF-008: motor doble-seis con 28 fichas.
- RF-009: marcador acumulativo hasta el objetivo seleccionado.

## No funcionales

- Seguridad OWASP MASVS como referencia.
- Backend autoritativo para online.
- Tiempo de respuesta objetivo menor de 250 ms en acciones de mesa.
- Cobertura mínima objetivo del dominio: 80%.
- Accesibilidad: contraste, tamaños táctiles y semántica de controles.
