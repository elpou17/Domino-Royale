# Domino Royale — Royale Edition v2.0.0

Proyecto Flutter Android para Visual Studio Code, construido sobre la base estable v1.2.1.

## Funciones incluidas

1. Flujo Splash → autenticación → bono/desafíos → selección Robots/Online.
2. Catálogo de Dominó Clásico, Mano a Mano y Dominó Abierto.
3. Salas por nivel con saldo mínimo y costo de entrada.
4. Selección de partidas a 50, 100 o 200 puntos.
5. Bono diario de 5 días y panel de desafíos.
6. Mesa verde de cuatro posiciones, fichas con puntos y turnos automáticos.
7. Detección visual de tranque y cierre por conteo.
8. Resultado de ronda, marcador Nosotros/Ellos y premio final.
9. Chat de mesa con mensajes rápidos.
10. Menú completo dentro de la partida.
11. Panel de emojis y reacciones.

> El modo online y los accesos Google/Facebook son flujos locales preparados para futura integración con Firebase y backend WebSocket.

## Compilar APK debug

```text

```

Salida:

```text

```
